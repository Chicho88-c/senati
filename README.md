# Login SENATI

Página de inicio de sesión con fondo negro, diseño adaptable y campos de correo y contraseña.

## Cómo abrir
Abre el archivo `index.html` en cualquier navegador.

## Importante
Esta es una interfaz de demostración. El formulario todavía no valida usuarios ni guarda contraseñas. Para tener un inicio de sesión real, debe conectarse a un backend y una base de datos con contraseñas protegidas mediante hash.
